# 点击器 v1.3

Android 悬浮连点器，支持**无障碍**与 **Root** 双引擎，白色苹果毛玻璃风格界面。

## v1.3 更新
- **速度大幅提升**
  - 无障碍模式：把连续多次点击打包成一个多笔画手势一次下发（每批最多 10 次），省掉“点一次等一次系统回调”的往返；按“起点到起点”精确计时。
  - Root 模式：常驻“极速注入器”直接向系统输入服务注入触摸事件，不再每次启动 `input` 进程；注入器不可用时自动降级为兼容模式。
  - 默认按住时长 50ms → 20ms，默认间隔 50ms，可在主界面改。
- **停止更可靠**
  - 运行时面板自动切换为“实时统计 + 大号停止键”，手指一按下就停（不等抬起）。
  - 通知栏新增“停止点击”按钮，作为第二个保底入口。
  - 引擎每批都检查停止标志，最多 0.3 秒内完全停下；手势被系统打断（比如你碰了屏幕）不再误报错退出。
- **全新界面**：白色毛玻璃卡片 + 柔和彩色光斑背景，圆形操作键，按钮改为“增加 / 开始 / 停止 / 保存”。
- 应用改名为“点击器”，新增应用图标。

## 构建 APK
推送到 GitHub 后 Actions 会自动执行 `gradle assembleDebug`，在运行页面底部 Artifacts 下载 `Clicker-debug-apk`。
也可以用 Android Studio（JDK 17 + SDK 34）直接编译。
